# What Makes High-Quality Coffee?

This project is a narrative visualization created with D3.js.

The visualization explores different characteristics related to coffee quality.

## Scenes

- Scene 1: Acidity and Overall Quality
- Scene 2: Aroma and Flavor
- Scene 3: Sweetness and Overall Quality

## Features

- Three narrative scenes
- Next button navigation
- Tooltips
- Annotations
- Interactive scatter plots

## Files

- index.html - main visualization
- coffee.csv - coffee dataset
- README.md - project information

## How to Run Locally

Because the project loads a CSV file, it should be opened through a local web server.

In the project folder, run:

```bash
python -m http.server 8000
```

Then open:

```
http://localhost:8000
```
